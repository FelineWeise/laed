Design rules (v3)
  • No emoji — line icons only (mic, folder, sparkle, capture viewfinder, share-upload, eye).
  • No static instructional copy under shutters or inside dropdowns — use hover/focus tooltips (data-tip).
  • Share icon → project list; privacy note lives on each project option’s hover tip.
  • Transient toasts after actions are fine (not permanent clutter).
