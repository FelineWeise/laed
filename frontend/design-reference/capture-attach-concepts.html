A — Filmstrip → right rail Projects live on the right as soft drop magnets. Session stays a horizontal film under the shutter. Best when you already know which project you’ll file into.
B — Unified dock One continuous bar: session on the left, projects on the right, hairline in the middle. Drag sideways within the dock — no side panel chrome. Most seamless on phone width.
C — Expanding session sheet Tray floats over the viewfinder. “Add to project” expands it into a project list (tap-first, great for touch). Collapses again so capture stays full-bleed.
