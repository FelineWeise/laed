Attach design
• Projects rail (left): always available while capturing; collapse to a thin strip if you need space.
• Desktop / trackpad: drag a tray card → project row highlights → drop → toast “Added privately to …”. Uses existing attach API (is_private: true).
• Touch: tap a card (selects it), then tap a project — same attach, no drag required. Hint text switches accordingly.
• Linked captures show a small green mark on the card; release visibility later in Project Room Files.
• No “Parakeet” (or any vendor) in the UI — only Live transcription + the text.
