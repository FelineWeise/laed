Idea 1 — Two-step sheet Project first, then Private / Shared. Shared expands to per-member toggles (+ optional “by role”). Most flexible at capture time · heaviest UI · needs backend for member/role ACL now
Idea 2 — Lock badge → Project Room Attach always private. Lock on the artifact; tap opens Project Files to unlock (eye) for all / later selective. Simplest Capture · matches today’s eye/eye-off · member-level can land later in Room
Idea 3 — Progressive toggle Default Private. Switch to Shared → choose Everyone / People / Roles. Keeps the sheet calm until you ask for more. Middle path · ship Private+Everyone first · People/Roles as follow-up
